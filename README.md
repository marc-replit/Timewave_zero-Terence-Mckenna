# Timewave Zero Streamlit App

[<image-card alt="Streamlit App" src="https://static.streamlit.io/badges/streamlit_badge_black_white.svg" ></image-card>](https://your-app-name.streamlit.app)  <!-- Replace with your deployed URL if you host it -->

A modern, interactive web app for exploring Terence McKenna's Timewave Zero novelty theory. Built with Streamlit, this tool visualizes fractal timewaves based on I Ching hexagrams using various primitives (Kelley, Watkins, Sheliak, HuangTi, Original McKenna).

Features include:
- Interactive novelty wave plots for each primitive
- Resonance peak/valley detection with tunable parameters
- Level-by-level animation buildup
- Historical and custom event overlays
- BCE/CE date support with proleptic Gregorian handling
- Math tools: Equations, live calculator, Python code export, Excel workbook generation
- I Ching hexagram viewer and random "throw" generator

This is a faithful re-implementation of the original 1990s software by Peter Meyer and Terence McKenna, updated for 2026 with modern web tech.
